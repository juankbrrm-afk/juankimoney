# 05 — Estudio de Fotos IA (Fase 6)

**Estado:** real, requiere validar calidad antes de confiar 100%.

Usa Gemini 2.5 Flash Image ("Nano Banana") vía API de Google — un modelo de
edición de imagen especializado en mantener el objeto principal intacto
(prenda: color/textura/estampado/diseño) mientras cambia modelo, fondo,
iluminación y escenario. Prompts base en `../prompts/image-photoshoot-prompt.md`
con variantes: caminando, Casco Viejo, Costa del Este, café, rooftop,
restaurante, playa.

**Advertencia real:** ningún modelo de imagen garantiza fidelidad perfecta
de la prenda al 100% siempre — hay que revisar a ojo las primeras tandas
antes de automatizar sin supervisión.
