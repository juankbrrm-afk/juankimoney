# 09 — Atención al Cliente IA (Fase 10)

**Estado:** real, pero es el cuello de botella de tiempo de todo el roadmap.

Instagram/Facebook Messenger + WhatsApp Business Cloud API → webhook a
n8n → Claude genera la respuesta con contexto de marca/pedidos → responde
por la misma API.

**Por qué toma tiempo:** Meta exige un proceso de revisión de app
("App Review") para los permisos de mensajería avanzados, más
verificación de negocio. Esto puede tomar de días a semanas y no depende
de nosotros — hay que iniciar la solicitud lo antes posible, en paralelo
a todo lo demás, no dejarlo para el final.
