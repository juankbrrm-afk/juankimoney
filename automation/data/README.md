# Data

Documentación del modelo de datos (hojas de Google Sheets usadas como base
de datos gratuita): `sourcing`, `scored`, `published`, `content_log`,
`orders_log`, `support_log`. Esquema completo de columnas se define en la
Fase 2 de implementación.

Si el volumen crece más allá de lo que Google Sheets aguanta cómodo,
siguiente paso natural es migrar a Airtable (tier gratis más generoso) o
Postgres — no es necesario para el arranque.
