# Prompts

Templates de prompts reutilizables para cada paso de IA del sistema
(scoring, copy/SEO, fotos, video, soporte al cliente, reportes).

Se escriben en la Fase 2 de implementación (después de aprobar esta
arquitectura) — cada uno versionado como archivo `.md` independiente,
referenciado por los workflows de `../n8n/flows/`.
